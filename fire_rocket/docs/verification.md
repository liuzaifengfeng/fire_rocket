## Python 上位机追加验证

本轮新增 `upper_computer.py` 和双击启动脚本，使用本机 Python 3.13 + Tk + pyserial 实际启动窗口，并通过 COM19 只读连接用户已经烧录的基础版固件。

- 实物返回：`config=0`、`samples=0`、`fresh=0`、`zeroed=0`、`storage=NEED FORMAT`。因此确认尚无有效传感器数据，不能仅通过归零解决 T 无效的问题；具体 UART 原因仍待诊断版字节计数核查。
- 上位机已实际验证板卡响应、旧协议兼容、窗口及各标签页创建。窗口截图与只读日志位于 `test-results/gui/`。
- 追加后 C++ 核心 2,432 条、应用/记录 86 条断言通过，Python 模型/串口分段/导出共 11 项测试通过。
- 新增 `DIAG`、`RXHEX`、`RAW` 的固件编译通过：RAM 19,944 字节，Flash 370,950 字节。**未烧录该诊断版**，当前板上的 UART 字节数仍不可知。
- 本轮未执行归零、参数修改、格式化、记录覆盖或任何输出操作；传感器实物数据解析恢复仍未验证。

## 主要覆盖

- AS201 三种模块类型及 256 种订阅掩码，共 768 种组合；有符号数、单位换算、ACK 与数据帧区分。
- 拆包、校验和错误、损坏帧尾/长度、重新同步、10 万个噪声字节。
- 连续稳定数据归零、超时失效、模块/字段变化、倾角、时间戳回绕、10 秒窗口环形缓冲。
- 按键消抖、长短按互斥，以及真实应用路径中的记录二次确认和长按停止。
- 配置非法值、记录期间配置锁定、记录覆盖、时间上限、空间不足、写入失败。
- USB 导出分段发送、零发送空间、断开连接、尾部不完整记录、超长命令整行丢弃。
- 缺失字段记录为 NaN；配置与数据源切换清除旧基准；遥测固件拒绝 ARM 命令。

## 未验证与未实现

首版交付时没有执行烧录、连接实物串口、OLED 目视检查、传感器安装轴向校验、真实 Flash 时序测量或飞行试验。本轮增加了上文所列的只读 USB 联调；测试桩仍不验证电源、GPIO 上电波形、传感器运动误差或 LittleFS 掉电一致性。

未实现二级点火、开伞、起飞识别、自动待发、延时/预测控制、评分优化及任何执行器脉冲。软件中的低电平初始化不是实物输出波形合格证明。本固件仅用于显示、记录和传感器数据检查。
